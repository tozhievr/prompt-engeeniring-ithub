# Командные проекты

Каждая команда создаёт отдельную ветку вида `team/<slug>` и работает **только** в папке `projects/<slug>/`.

Минимальный набор:
```
projects/neon-runner/
  index.html
  README.md
  js/
  assets/
```

Не используйте npm, Node.js и сборщики. Все необходимые JS/WASM и ассеты должны быть доступны локально. Для загрузки модулей запускайте `python -m http.server 8000` из корня репозитория и открывайте `http://localhost:8000/projects/neon-runner/`.

## Публикация

1. Создайте ветку `team/neon-runner` от `main`.
2. Коммитьте изменения в `projects/neon-runner/`.
3. Откройте Pull Request в `main`. GitHub Actions запустит статические и браузерные проверки.
4. В CI появится ZIP-артефакт `site-preview-...`; это **не** публичный URL.
5. После одобрения преподавателем PR объединяется с `main`, а Pages публикует галерею.
6. Сайт: https://tozhievr.github.io/prompt-engeeniring-ithub/ (после включения Pages в настройках).

**Важно:** ветки не публикуются автоматически на публичном Pages; опубликованная версия соответствует `main`.

Не коммитьте секреты, пароли, чужие лицензированные медиа и большие файлы. Учтите: содержимое опубликованных проектов публично.
